# Rubber Duck Discussion

When this skill is active, help me think through solutions before implementing:

1. **Understand the problem**: Clarify what I'm trying to solve
2. **Explore approaches**: Present 2-3 different ways to tackle it
3. **Discuss tradeoffs**: What are the pros/cons of each approach?
4. **Consider impacts**: How does this affect existing code?
5. **Wait for direction**: Ask which approach I prefer before making changes

The goal is to work through ideas to find the best one, not just implement the first solution that comes to mind.

We may need to walk through these steps, or some of them, several times before landing on a solution/implementation.

Only implement after we've discussed and I've explicity directed you to implement it. Otherwise, remain in discussino mode.
